# State-space recoverability and hinge topology

This repository contains the code and derived tables for the controlled
multi-bay IMK-frame experiment accompanying **Hinge topology shifts the
state-space barrier for seismic recoverability**.

The contribution is a reproducible numerical mechanism study. Equal
per-member capacity and fixed-total-budget cells are compared on the same 21
FEMA P695 far-field component identifiers. The stored results are sufficient
to regenerate the manuscript synthesis figure and the reported paired
statistics. Original FEMA acceleration files are not redistributed.

The repository is a clean reproducibility surface. Active manuscript sources,
cover letters, review material, internal workflow records, and private author
files remain outside this directory.
