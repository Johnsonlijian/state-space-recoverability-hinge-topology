# State-space recoverability and hinge topology

This repository contains the baseline oscillator and one-bay frame sources,
the derived tables, and the controlled multi-bay IMK-frame experiment
accompanying **Hinge topology shifts the state-space barrier for seismic
recoverability**.

The contribution is a reproducible numerical mechanism study. Equal
per-member capacity and fixed-total-budget cells are compared on the same 21
FEMA P695 far-field component identifiers. The stored results are sufficient
to regenerate the manuscript synthesis figure (`figures/fig8_multibay.pdf`)
and the reported paired statistics. Original FEMA acceleration files are not
redistributed.

The repository is a clean reproducibility surface. Active manuscript sources,
cover letters, review material, internal workflow records, and private author
files remain outside this directory. A persistent public archive DOI has not
yet been assigned to this local release; the manuscript remains local-only
until the release is deposited in a permitted repository.
