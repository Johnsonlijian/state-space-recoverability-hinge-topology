# FEMA P695 far-field components

The analysis uses 21 even-numbered far-field component identifiers from the
FEMA P695 set (FF00--FF42, with the incomplete local FF34 component omitted).
The original acceleration files are third-party source data and are not
redistributed in this package. Place legally obtained files named `FF*.txt`
in this directory before running the dynamic census. The derived JSON tables
in `../results/` preserve the record identifiers, scale factors, time steps,
and response values used for the manuscript.
